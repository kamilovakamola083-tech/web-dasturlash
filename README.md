- **`amaliy-01/`** — 1-amaliy topshiriq

  - **`batafsil.html`** — Batafsil ma'lumot sahifasi
  - **`css/`** — Loyihaning CSS stil fayllari (`style.css`)
  - **`README.md`** — Loyiha haqida ma'lumot

- **CSS3** — Sahifa dizayni va stili
